Open Virtual Memory Simulator.py
Run the file
A new pop up window will appear
You can select the algorithm which you want to run
You can select packet order randomly by generate  button or manually entering
There are preset sequences for thrashing, Belady and high locality along with making random sequences.
You can manually select number of frames
For Enhanced second chance, you also have a r/w string which can be changed manually
Add-Ref Bits have a Timer interrupt which can be used.
Step button to be used to observe how algo works
Run all to do all simulation at once
Show Graph to see number of faults per frame on given sequence and algorithm
Note: Load/Reset to be used before running algorithms to clear cache when inputs are changed
Statistics and log shows , Faults, Hits and Hit rate
